# MindNotes

零依赖、纯前端的思维导图式学习笔记工具。

## 特性
- 思维导图式编辑：拖动、折叠、缩放、平移
- 节点内嵌富文本：文字 / 图片 / 表格
- 多笔记工作区（侧边栏切换）
- 撤销 / 重做
- 跨设备云端同步：支持 **GitHub** 或 **Gitee** 作为后端
- 未配置云端时自动用浏览器本地存储兜底
- 零外部依赖，零 CDN

## 本地使用
直接双击 `index.html` 打开即可。
> 部分浏览器对 `file://` 下的 fetch 有限制（云端同步会受影响），建议起一个本地静态服务：
> ```
> python -m http.server 8000
> ```
> 然后访问 http://127.0.0.1:8000

## 部署
任意静态托管（GitHub Pages / Vercel / Netlify / 自建 nginx）都适用，因为是纯静态文件。

## 云端存储
打开 ⚙ 设置：
- **存储平台**：GitHub（国际，需稳定网络）或 Gitee（国内直连）
- 填用户名 / 仓库名 / 分支 / Personal Access Token
- 点「测试连接」验证 → 保存

之后工具栏 💾 推送到云端，🔄 从云端拉取。

> Token 仅保存在本机浏览器 `localStorage`，不会上传到任何第三方。

## 文件
- `index.html` — 入口
- `app.js` — 全部逻辑（思维导图 + 云端 + 工作区）
- `style.css` — 样式
- `_smoke.js` / `_gitee_test.js` — 回归测试（可选，不影响运行）
